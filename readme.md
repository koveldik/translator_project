# Translator Project

Простой веб‑переводчик текста в браузере.

**Автор:** Картавцев Иван Дмитриевич, группа МИБ-301

## Описание проекта

Веб-приложение, которое позволяет переводить введённый пользователем текст между несколькими языками прямо в браузере.  
Пользователь выбирает язык исходного текста и язык перевода, вводит текст и получает результат на выбранном языке.

Для перевода текста используется публичное API MyMemory:  
`https://api.mymemory.translated.net/get`  
Запрос отправляется с параметрами:
- `q` — текст для перевода;
- `langpair` — пара языков в формате `исходный|целевой` (например, `en|ru`, `ru|en`, `es|fr`). [file:1]

В рамках зачета по МБ в проект была добавлена новая функциональность:
- Реализована **история переводов**: на странице отображаются последние выполненные переводы (исходный текст и результат), что позволяет быстро вернуться к предыдущим запросам.

## Поддерживаемые языки

- Английский (en)  
- Русский (ru)  
- Испанский (es)  
- Французский (fr)  
- Немецкий (de)

## Стек технологий

- **HTML, CSS** — структура и оформление интерфейса.
- **JavaScript (Vanilla JS)** — обработка ввода, логика перевода, работа с DOM и историей запросов.
- **MyMemory Translation API** (`https://api.mymemory.translated.net/get`) — внешний сервис перевода текста, который используется для получения результата перевода. [file:1]

##  Быстрый старт

1. Клонировать репозиторий


2. Открыть файл `index.html` в браузере:
- Дважды кликнуть по `index.html` в проводнике / Finder  
или  
- Запустить через локальный сервер (например, Live Server в VS Code / Cursor).

3. В интерфейсе:
- Выбрать язык исходного текста (например, ru).
- Выбрать язык перевода (например, en).
- Ввести текст для перевода и нажать кнопку перевода.
- Посмотреть результат и при необходимости воспользоваться историей предыдущих переводов.

## Реализованные функции

- Перевод текста между пятью языками: en, ru, es, fr, de.
- Формирование запроса к MyMemory Translation API с использованием параметров `q` и `langpair`. [file:1]
- Отображение результата перевода на той же странице без перезагрузки.
- **Новая функциональность:** история переводов (список последних запросов с исходным текстом и переведённым результатом).
